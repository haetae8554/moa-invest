# Chrome 웹 스토어 소개 초안

등록·결제·업로드·심사 요청은 수행하지 않았습니다. 최종 패키지와 일치하는지 확인한 뒤 사용하세요.

**이름:** 모아 · 토스 종목 연결

**짧은 설명:** 토스 탭 옆에서 보유 종목을 확인하고 소수점 분할 주문을 계획하세요. Windows PC 연결 도구가 필요합니다.

**상세 설명:**

모아는 토스증권 Open API와 연결하는 개인용 투자 데스크입니다. 토스 탭 옆의 Chrome 사이드 패널에서 보유 종목을 확인하고, 전체 금액이나 수량을 기준으로 매수·매도 주문을 약 $9씩 나눠 전송할 수 있습니다.

- 내 투자 조회: 보유 종목, 수량, 평가금, 손익을 검색·정렬합니다.
- 종목 연결: 토스와 모아 중 한쪽에서 선택한 종목을 다른 쪽에도 반영합니다.
- 분할 주문: 매수·매도와 총금액·총수량을 선택한 뒤 계획을 확인합니다.
- 진행 확인: 접수 내역을 확인하고 아직 전송하지 않은 주문을 중단합니다.
- 화면 설정: 시스템·라이트·다크 테마와 좁은 패널에 맞춘 화면을 제공합니다.
- 연결 없는 데모: 계좌·키를 넣지 않고 고정된 가상 데이터로 계산 예시를 볼 수 있습니다.

사용 환경: Windows, Chrome 141 이상, 별도 PC 연결 도구, 본인의 토스증권 Open API 인증 정보가 필요합니다. Python 포함 연결 도구는 Python 별도 설치가 필요 없고, 소스 실행 방식은 Python 3.11 이상이 필요합니다. 확장만 설치하면 실제 계좌 기능이 바로 실행되는 제품은 아닙니다.

API 키는 로컬 UI에서 입력하고 Windows 자격 증명 관리자에 보관합니다. 개발자 수집 서버로 보내지 않습니다. 확장은 선택한 종목의 식별자와 연결 설정을 처리하며, 공개 종목 조회 서버와 통신합니다. 자세한 내용은 개인정보 처리 안내를 확인하세요.

실제 주문은 실주문 모드를 켜고 미리보기에서 시작을 선택해야 전송됩니다. 접수와 체결은 다릅니다. 패널이나 Chrome을 닫아도 PC 서버가 실행 중이면 시작한 주문은 계속될 수 있습니다. 중단 기능은 이미 접수한 주문을 취소하지 않습니다. $9는 분할 기준이며 수수료 면제·투자 수익·체결을 보장하지 않습니다.

토스증권의 공식 서비스가 아닌 독립 프로젝트입니다. 토스 웹사이트의 종목 조회 방식이 변경되면 연결 기능이 일시적으로 제한될 수 있습니다.

- 검토용 실제 캡처: [demo-review.jpg](assets/demo-review.jpg). 가상 데이터로 렌더링한 독립 데모 화면이며 토스 화면이나 실제 계좌 화면을 합성하지 않았습니다.

- 토스 로고나 공식 제휴를 연상시키는 문구를 홍보 이미지에 추가하지 않습니다.
