모아 Windows 연결 도구 — 시험 배포본 (서명되지 않음)

Python이 포함되어 있어 Python을 따로 설치할 필요가 없습니다.
Chrome 웹 스토어 등록이나 심사를 완료한 제품이 아닙니다.

1. ZIP 전체를 본인 계정으로 쓰기 가능한 폴더에 풀어 주세요.
   MoaHelper.exe와 _internal 폴더를 함께 유지하세요.
2. Install.cmd를 실행하면 현재 사용자에게만 Chrome 연결 도구를 등록합니다.
   관리자 권한이나 로그인 자동 실행 등록은 필요하지 않습니다.
3. 모아 확장을 로드/새로고침하고 사이드 패널을 여세요.
   이후에는 실행 파일이나 배치 파일을 매번 실행할 필요가 없습니다.
4. 패널의 API 키 설정에서 본인의 키를 등록하세요.

원본 소스 버전과 이 패키지를 동시에 설치·실행할 필요는 없습니다.
새 패키지의 data/는 원본 소스의 data/와 별개입니다.
기존 주문 기록은 자동 이관하지 않으며 Windows 저장 키는 공유될 수 있습니다.
기존 도구를 사용하던 PC에서는 진행 중이거나 결과가 불확실한 주문부터 확인하고,
기존 서버를 종료한 뒤 다른 설치 위치로 전환하세요. 기존 DB는 보관하세요.

보안 / 종료 / 삭제
- 키는 Windows 자격 증명 관리자에 보관하며 개발자 서버로 보내지 않습니다.
- 새로 등록한 키의 OAuth 토큰은 서버 메모리에 보관합니다.
- 주문 기록은 이 폴더의 data/에 저장됩니다. 공개하거나 ZIP으로 재배포하지 마세요.
- 창이나 Chrome을 닫아도 시작한 주문은 PC에서 계속될 수 있습니다.
  주문 기록의 '남은 주문 중단'을 사용하세요. 이미 접수한 주문은 취소되지 않습니다.
- Uninstall.cmd는 연결 등록만 해제합니다. 실행 중인 서버·키·주문 기록은 유지됩니다.
- 개인정보 보관·삭제는 함께 제공되는 PRIVACY.md를 확인하세요.
- 업데이트 파일을 기존 data/ 위에 덮어쓰거나 주문 중 서버를 강제 종료하지 마세요.

파일 서명이 없으므로 배포자를 검증하는 서명 인증서는 제공되지 않습니다.
보안 경고를 무시하거나 보안 기능을 끄는 설치 절차는 제공하지 않습니다.
공개 배포 전 코드 서명과 별도 Python이 없는 Windows PC 검증이 남아 있습니다.
