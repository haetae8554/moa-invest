토스 ↔ 모아

종목은 자동으로 연결해요

  1. 이미 확장을 설치했다면 Chrome 확장 관리 화면에서 모아 · 토스 종목 연결의 새로고침 버튼을 눌러 주세요.
  2. 같은 Chrome 창에서 토스와 모아를 새로고침하세요. 두 탭이 하나씩 열려 있으면 자동 연결돼요.
  3. 토스나 모아에서 종목을 선택하면 상대 화면의 종목도 바뀌어요. 종목별 등록은 필요 없어요.

탭을 여러 개 열었을 때만 확장 메뉴에서 사용할 두 탭을 선택하세요. 자동 조회 오류는 연결 상태에 표시돼요.

처음 설치할 때는 Chrome 확장 관리의 개발자 모드 → 압축해제된 확장 프로그램 로드에서 프로젝트의 browser_extension 폴더를 선택하세요.
