연결 없이 데모 보기프로젝트 · 설치 안내 ↗

처음 한 번만 연결해 주세요

  1. Windows 연결 도구 준비

    Python 포함 Windows 패키지는 압축을 풀고 Install.cmd를 실행하세요. 소스 버전은 Python 3.11 이상과 install-extension.bat을 사용합니다. 두 방식을 동시에 설치할 필요는 없습니다.

  2. 토스 탭에서 모아 열기

    확장 아이콘 → 사이드 패널 열기. 서버가 없으면 자동으로 시작합니다. 별도 화면은 ‘새 탭으로 열기’를 사용하세요.

  3. API 키 설정

    패널의 API 키 설정에서 본인의 Client ID와 Client Secret을 등록하세요. Windows 자격 증명 관리자에 저장하며 저장 후 실주문은 꺼집니다.

Windows 실행 파일은 현재 서명되지 않은 시험 배포본입니다. 스토어에 게시되지 않았으며, Python을 포함한 연결 도구도 PC에 별도로 필요합니다.

켜기·끄기

종목 연결 끄기는 선택 종목 동기화만 멈춥니다. 패널 닫기는 화면만 닫습니다. 이미 시작한 주문을 멈추려면 주문 기록의 남은 주문 중단을 사용하세요. 이미 접수된 주문은 취소되지 않습니다.

키 입력이나 종목 선택만으로 주문을 보내지 않습니다. 실제 전송에는 실주문 활성화와 미리보기 확인 후 시작이 필요합니다.

내 정보는 어디에 있나요?

API 인증 정보
PC의 Windows 자격 증명 관리자. 새로 등록한 키의 OAuth 토큰은 서버 메모리에만 유지합니다.
주문 기록
PC 연결 도구의 data/ 폴더. 확장을 삭제해도 자동으로 삭제되지 않습니다.
확장 설정
브라우저의 로컬 설정·종목 정보 캐시. 탭 연결 정보는 브라우저 세션 저장소에 보관합니다.
외부 통신
선택한 종목 코드·티커는 토스 종목 조회 서버로, 계좌 조회와 주문은 PC 서버에서 토스 Open API로 전송합니다. 개발자 수집 서버·광고·분석 도구는 없습니다.

확장 페이지는 API 키를 전달받지 않습니다. 키 등록 화면은 별도 로컬 웹 출처로 분리되어 있습니다.

개인정보 처리 및 삭제 방법 ↗

연결이 안 될 때

Chrome 141 이상인지 확인하고 확장을 새로고침하세요. 연결 도구를 옮겼다면 다시 등록해야 합니다. 다른 프로그램이나 이전 서버가 8765 포트를 사용하면 진행 중인 주문부터 확인해 주세요.

연결 도구 해제는 Uninstall.cmd, 소스 버전은 python scripts/install_native_host.py --uninstall입니다. 키·주문 내역·실행 중인 서버는 유지됩니다.
