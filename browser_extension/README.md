# 모아 · Chrome 투자 패널 (0.3.0)

토스 탭 옆에 모아를 펼쳐 내 투자·분할 주문·API 키 설정을 사용합니다. 별도의 모아 탭은 필요 없습니다. 로컬 Python 서버가 필요하며 Chrome 웹 스토어에는 아직 게시하지 않았습니다.

## 처음 설치하기

1. **Chrome 141 이상**을 사용합니다. `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**로 이 폴더를 선택합니다.
2. 프로젝트의 `run.bat`으로 서버를 실행합니다. 추가 탭은 자동으로 열리지 않습니다.
3. 토스 탭을 새로고침한 뒤 확장 아이콘 → **사이드 패널 열기**를 선택합니다.
4. 패널의 **API 키 설정**에서 키를 등록하거나 기존 Windows 저장 키를 사용합니다.

패널에서 보는 주문 화면은 `http://127.0.0.1:8765/panel`입니다. 확장은 키·계좌 데이터를 전달받지 않고 종목 식별자만 교환합니다. 서버가 꺼져 있으면 실행 안내와 **다시 연결** 버튼이 표시됩니다. 서버를 먼저 실행한 뒤 다시 연결하세요.

## 0.2.0에서 업데이트하기

고정된 확장 ID로 패널 접근을 제한하도록 변경했습니다. **기존 확장을 제거한 후 같은 폴더를 다시 로드**하세요. 이때 확장의 종목 캐시·탭 연결 설정은 초기화되지만 서버의 API 키·주문 기록은 유지됩니다. 토스 탭도 새로고침하세요. 이후 같은 ID의 버전에서는 확장 관리의 새로고침을 사용하면 됩니다.

이 배포의 확장 ID는 `kidibaplcnnchoajokdjnalihnlhhibl`입니다. `manifest.key`는 공개 식별용 키이며 비밀 API 키가 아닙니다. 로컬 서버와 확장을 함께 업데이트해야 합니다. 웹 스토어 배포에서 ID가 바뀌면 서버의 프레임 허용 대상도 갱신해야 합니다.

## 켜기·끄기와 두 가지 사용 방식

| 기능 | 동작 |
| --- | --- |
| 사이드 패널 열기 / 패널 닫기 | 토스 화면 옆 모아를 표시하거나 숨깁니다. 별도 탭을 만들지 않습니다. |
| 종목 연결 켜짐 / 꺼짐 | 패널은 유지하고 종목 동기화만 일시정지합니다. 설정은 저장됩니다. |
| 기존 탭으로 열기 | 기존 모아 탭을 활성화하거나 하나만 새로 엽니다. |
| 두 탭 연결 · 고급 설정 | 종전의 토스↔모아 탭 연결을 다시 설정합니다. |

사이드 패널은 **그 창의 현재 활성 토스 탭**을 따라갑니다. 다른 사이트로 전환하면 종목 연결을 기다립니다. 이전 두 탭 연결은 패널 사용 시 일시정지해 서로 종목을 덮어쓰지 않게 합니다. 탭 방식으로 돌아가면 고급 설정에서 연결을 다시 켜세요.

**패널 닫기와 주문 중단은 다릅니다.** 패널을 닫아도 서버가 살아 있으면 이미 시작한 분할 주문은 계속됩니다. 주문 기록의 **남은 주문 중단**으로 멈추세요. 이미 접수한 주문은 취소되지 않습니다.

## 실제 Chrome 확인 항목

자동 테스트는 패널 메시지·활성 탭 선택·일시정지·잘못된 출처 거절을 검증합니다. 개발 도구는 일반 Chrome에 연결되지 않아 아래 실제 확장 화면 동작은 설치 환경에서 확인해야 합니다.

- 패널 열기/닫기, 서버 종료 시 안내와 다시 연결.
- API 키 설정 모달 열기, 키 저장 후 실주문 꺼짐.
- 토스 종목 선택 → 패널, 패널 종목 선택 → 토스 이동.
- 종목 연결을 끄면 두 화면의 선택이 독립적으로 유지되는지.

## 자동 조회와 오류 처리

- `https://wts-info-api.tossinvest.com/api/v2/stock-infos/code-or-symbol/{티커 또는 코드}`의 GET 응답에서 `result.code`와 `result.symbol`을 확인합니다. 요청한 식별자와 응답이 정확히 일치해야 선택을 전달합니다. 추측으로 주소를 만들지 않습니다.
- 검증한 종목 정보는 로컬 확장 저장소에 24시간 캐시합니다. 같은 종목은 양방향 모두 캐시를 사용합니다. 최대 1,000개까지 보관합니다.
- 타임아웃은 6초입니다. 일반 통신 실패는 30초 동안 재조회하지 않습니다. 401/403/429 응답은 자동 조회를 중지하고 상태에 오류를 표시합니다. 연결 상태를 확인한 뒤 확장 메뉴의 **종목 정보 다시 조회**로 재시도할 수 있습니다.
- 웹 조회는 공식 주문 Open API와 별개인 웹사이트 내부 인터페이스여서 변경되거나 접근이 제한될 수 있습니다. 개발 환경의 직접 요청은 403을 반환했지만, 2026-10-15 사용자 Chrome에서 업데이트 후 `토스 ↔ 모아 · 종목명` 상태가 표시됨을 사용자 응답으로 확인했습니다. 이는 실제 종목 조회와 최초 선택 적용 확인이며, 이후 양방향 클릭 전체 과정은 별도 실사용 확인 범위입니다.
- 구현 시 엔드포인트 및 응답 필드는 공개된 [조회 코드](https://github.com/dd3ok/tossinvest-api-skill/blob/main/scripts/stock_page.py)를 참고했습니다. 외부 코드를 설치하거나 실행하지 않았습니다.

## 동작 범위

연결은 선택된 두 탭에만 적용됩니다. 모아의 연결 버튼이나 확장 메뉴에서 일시정지할 수 있고, 일시정지 설정은 재시작해도 자동으로 풀리지 않습니다. 다시 켜면 토스의 현재 종목을 모아에 적용합니다. 탭을 닫으면 연결이 해제되며 새로 연 탭이 같은 창에서 하나씩인 경우 자동 연결을 다시 시도합니다.

토스 이동은 종목 링크 또는 조회로 확인한 `/stocks/내부코드/order` 주소로만 합니다. 화면 전체 탐색이 필요한 경우 토스의 미완료 입력값이 초기화될 수 있으므로 입력을 보존하려면 연결을 잠시 끄세요. 모아는 외부에서 종목이 바뀌면 기존 미리보기를 닫고, 처리 중이면 완료 후 최신 종목을 적용합니다. 이미 시작한 분할 주문은 원래 종목으로 진행됩니다.

Chrome 절전과 백그라운드 제한에 따라 지연될 수 있습니다. 두 화면을 함께 보는 환경에서 약 1.2초마다 토스 종목 주소 변경을 확인하며 이 확인마다 네트워크로 종목을 다시 조회하지는 않습니다.

## 권한과 검증

접근 범위는 토스 웹사이트, 공개 종목 조회 호스트, `http://127.0.0.1:8765/` 및 `http://localhost:8765/`입니다. 종목 조회에는 선택한 티커/코드만 보내며 API 키와 쿠키는 보내지 않습니다. 잔액, 보유수량, 손익, 계좌번호를 수집하지 않습니다. 확장 메시지로 주문 API나 주문 버튼을 조작하지 않습니다. 주문은 사용자가 별도 출처로 격리된 로컬 프레임에서 확인 후 시작합니다.

`sidepanel.*`이 패널 호스트, `popup.*`이 열기·닫기와 탭 설정을 담당합니다. [Chrome Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)를 사용합니다. `resolver.js`가 자동 조회·응답 검증·캐시를 담당하고, `background.js`는 탭 연결과 전달을 담당합니다. `toss.js`, `moa.js`는 화면 어댑터, `popup.*`은 연결 상태 설정입니다. `node --test tests/test_symbol_sync.cjs`는 모의 네트워크/브라우저로 자동 조회, 양방향 캐시, 탭 자동 선택, 오류 중단, 오래된 응답 폐기와 미리보기 무효화를 검증합니다.
