# 모아 · 토스 종목 자동 연결 (0.2.0)

종목마다 등록하는 절차를 없앴습니다. 선택한 종목의 티커와 토스 내부 코드를 웹 종목 정보 조회로 자동 변환합니다. 주문 Python 모듈과 독립된 Chrome Manifest V3 확장입니다.

## 이미 설치했다면

1. `chrome://extensions`에서 **모아 · 토스 종목 연결**의 새로고침 버튼을 누릅니다. 추가된 `wts-info-api.tossinvest.com` 접근 권한은 공개 종목 정보 조회에 사용합니다.
2. 같은 Chrome 창의 토스·모아 페이지를 모두 새로고침합니다.
3. 토스·모아 탭이 하나씩 있으면 자동으로 연결됩니다. 두 화면 중 한 곳에서 종목을 선택하면 상대 화면에도 반영됩니다. 처음 연결할 때는 토스 종목을 모아에 적용합니다.

여러 토스/모아 탭이 있으면 확장 메뉴에서 사용할 두 탭만 고릅니다. **종목별 티커 입력이나 등록은 없습니다.** 예전에 수동 등록한 매핑은 자동 조회에 사용하지 않습니다. 모아에서 티커를 직접 입력할 때는 입력칸을 벗어나면 전달됩니다.

처음 설치할 때만 확장 관리의 개발자 모드 → **압축해제된 확장 프로그램 로드**에서 이 폴더를 선택합니다. ZIP은 먼저 압축을 풉니다. 확장과 모아는 같은 Chrome 프로필에서 사용하며 Codex 내부 미리보기에는 Chrome 확장이 적용되지 않습니다.

## 자동 조회와 오류 처리

- `https://wts-info-api.tossinvest.com/api/v2/stock-infos/code-or-symbol/{티커 또는 코드}`의 GET 응답에서 `result.code`와 `result.symbol`을 확인합니다. 요청한 식별자와 응답이 정확히 일치해야 선택을 전달합니다. 추측으로 주소를 만들지 않습니다.
- 검증한 종목 정보는 로컬 확장 저장소에 24시간 캐시합니다. 같은 종목은 양방향 모두 캐시를 사용합니다. 최대 1,000개까지 보관합니다.
- 타임아웃은 6초입니다. 일반 통신 실패는 30초 동안 재조회하지 않습니다. 401/403/429 응답은 자동 조회를 중지하고 상태에 오류를 표시합니다. 연결 상태를 확인한 뒤 확장 메뉴의 **종목 정보 다시 조회**로 재시도할 수 있습니다.
- 웹 조회는 공식 주문 Open API와 별개인 웹사이트 내부 인터페이스여서 변경되거나 접근이 제한될 수 있습니다. 개발 환경의 직접 요청은 403을 반환했지만, 2026-10-15 사용자 Chrome에서 업데이트 후 `토스 ↔ 모아 · 종목명` 상태가 표시됨을 사용자 응답으로 확인했습니다. 이는 실제 종목 조회와 최초 선택 적용 확인이며, 이후 양방향 클릭 전체 과정은 별도 실사용 확인 범위입니다.
- 구현 시 엔드포인트 및 응답 필드는 공개된 [조회 코드](https://github.com/dd3ok/tossinvest-api-skill/blob/main/scripts/stock_page.py)를 참고했습니다. 외부 코드를 설치하거나 실행하지 않았습니다.

## 동작 범위

연결은 선택된 두 탭에만 적용됩니다. 모아의 연결 버튼이나 확장 메뉴에서 일시정지할 수 있고, 일시정지 설정은 재시작해도 자동으로 풀리지 않습니다. 다시 켜면 토스의 현재 종목을 모아에 적용합니다. 탭을 닫으면 연결이 해제되며 새로 연 탭이 같은 창에서 하나씩인 경우 자동 연결을 다시 시도합니다.

토스 이동은 종목 링크 또는 조회로 확인한 `/stocks/내부코드/order` 주소로만 합니다. 화면 전체 탐색이 필요한 경우 토스의 미완료 입력값이 초기화될 수 있으므로 입력을 보존하려면 연결을 잠시 끄세요. 모아는 외부에서 종목이 바뀌면 기존 미리보기를 닫고, 처리 중이면 완료 후 최신 종목을 적용합니다. 이미 시작한 분할 주문은 원래 종목으로 진행됩니다.

Chrome 절전과 백그라운드 제한에 따라 지연될 수 있습니다. 두 화면을 함께 보는 환경에서 약 1.2초마다 토스 종목 주소 변경을 확인하며 이 확인마다 네트워크로 종목을 다시 조회하지는 않습니다.

## 권한과 검증

접근 범위는 토스 웹사이트, 공개 종목 조회 호스트, `http://127.0.0.1:8765/` 및 `http://localhost:8765/`입니다. 종목 조회에는 선택한 티커/코드만 보내며 API 키와 쿠키는 보내지 않습니다. 잔액, 보유수량, 손익, 계좌번호를 수집하지 않습니다. 주문 API나 주문 버튼은 조작하지 않습니다.

`resolver.js`가 자동 조회·응답 검증·캐시를 담당하고, `background.js`는 탭 연결과 전달을 담당합니다. `toss.js`, `moa.js`는 화면 어댑터, `popup.*`은 연결 상태 설정입니다. `node --test tests/test_symbol_sync.cjs`는 모의 네트워크/브라우저로 자동 조회, 양방향 캐시, 탭 자동 선택, 오류 중단, 오래된 응답 폐기와 미리보기 무효화를 검증합니다.
